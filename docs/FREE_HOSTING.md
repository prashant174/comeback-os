# Free hosting + phone app (PWA)

Result: one HTTPS link (e.g. `https://comeback-os.onrender.com`) that works from anywhere, installed on your phone as an app icon. Total cost ₹0.

| Piece | Service | Free tier (check their site — limits change) |
|---|---|---|
| Database | MongoDB Atlas **M0** | 512 MB storage, shared cluster |
| App (API + website) | Render **Free web service** | 512 MB RAM, sleeps after ~15 min idle, ~750 instance-hours/month |
| Keep-awake ping | cron-job.org | free scheduled HTTP calls |
| Code | GitHub (private repo) | free |

Photos are stored inside MongoDB (GridFS), so nothing is lost when Render restarts — Render's free disk is wiped on every deploy/restart. Photos are compressed in the browser (~250 KB each) to keep within 512 MB.

## 1. Put the code on GitHub (private)
```powershell
cd C:\path\to\comeback-os
git init
git add .
git status          # make sure backend/.env and node_modules are NOT listed
git commit -m "Comeback OS"
```
Create a **private** repo on github.com (no README), then:
```powershell
git branch -M main
git remote add origin https://github.com/<you>/comeback-os.git
git push -u origin main
```
`.gitignore` already excludes `.env`, `node_modules`, `dist` and `uploads`. Never commit `backend/.env`.

## 2. Create the free database (MongoDB Atlas)
1. Sign up at mongodb.com/atlas → **Create** → **M0 Free** → provider AWS, region **Mumbai (ap-south-1)** → Create.
2. **Database Access** → Add user → username `cbos`, autogenerate a password → copy it → role *Read and write to any database*.
3. **Network Access** → Add IP → **Allow access from anywhere** (`0.0.0.0/0`). Render's free IPs are not fixed, so this is required; the strong password + TLS protect it.
4. **Connect** → Drivers → copy the string and add the database name `comeback_os`:
   ```
   mongodb+srv://cbos:<password>@cluster0.xxxxx.mongodb.net/comeback_os?retryWrites=true&w=majority
   ```
   If the password has special characters (`@ : / ? #`), URL-encode them.

## 3. (Optional) Move your existing local data to Atlas
Needs **MongoDB Database Tools** (mongodump/mongorestore) on Windows.
```powershell
mongodump --uri="mongodb://127.0.0.1:27017/comeback_os" --archive=cbos.gz --gzip
mongorestore --uri="mongodb+srv://cbos:<password>@cluster0.xxxxx.mongodb.net/comeback_os" --archive=cbos.gz --gzip --nsInclude="comeback_os.*"
```
Photos you uploaded locally *before this update* live in `backend/uploads/` on disk and won't move; re-upload them. New photos go to the database automatically.

## 4. Deploy on Render
1. Sign up at render.com with GitHub → **New → Blueprint** → choose the `comeback-os` repo. Render reads `render.yaml`.
2. When asked, fill:
   - `MONGO_URI` → the Atlas string from step 2
   - `CLIENT_URL` → leave a placeholder now (e.g. `https://comeback-os.onrender.com`); fix it after the first deploy shows your real URL
3. **Apply**. First build takes ~5 minutes. Open the URL when it shows *Live*.
4. If your URL differs from the placeholder: service → **Environment** → update `CLIENT_URL` → save (auto-redeploys).
5. Register your personal account.
6. **Admin login:** Environment → add `ADMIN_EMAIL` (a *different* email from your personal one) and `ADMIN_PASSWORD` (12+ characters, letters + numbers) → save. After the redeploy, log in with them → you land on `/admin`.
7. In Admin → Settings, turn sign-ups **off** when your friends have joined (or keep them off and use **Add friend** to create their accounts with a temporary password).

JWT secrets are generated by Render automatically. Every `git push` to `main` redeploys.

## 5. Keep it awake (so reminders fire and it opens fast)
Free Render sleeps after ~15 min without traffic; waking takes ~30–60 s (the app shows "Waking up the server…").
1. Sign up at cron-job.org → **Create cronjob**
2. URL: `https://<your-app>.onrender.com/api/health` · every **10 minutes** · save.

One always-on free service uses ~730 of the ~750 monthly free hours. If you skip this, the app still works — it's just slow on the first open, and reminders only fire if the server is awake within 30 min of their time.

## 6. Install on your phone
**Android (Chrome):** open your https link → log in → ⋮ menu → **Install app** (or Settings → Account → *Install app* button inside Comeback OS).
**iPhone (Safari only):** open the link → **Share** → **Add to Home Screen** → Add.

It opens full-screen with its own icon, remembers your login (30-day session), and the app shell loads even before the server wakes.

Notifications: Settings → Reminders → enable *browser notifications*. They show while the app is open/recently used. Background push with the app fully closed needs a push service (not built yet).

## Troubleshooting
| Problem | Fix |
|---|---|
| Render build fails at `tsc` / `vite: not found` | Build command must use `npm ci --include=dev` (already in render.yaml) |
| App starts then crashes: "Invalid environment variables" | `MONGO_URI` missing or JWT secrets not generated — check Environment tab |
| `MongooseServerSelectionError` in Render logs | Atlas Network Access must include `0.0.0.0/0`; check user/password in the string |
| Logged out every time on phone | `COOKIE_SECURE` must be `true` (https). Use the onrender.com link, not http |
| "Install app" option missing | Must be the https link, in Chrome (Android) or Safari (iPhone), not inside another app's in-app browser |
| Old version after deploy | Close and reopen the app twice (the service worker updates in the background) |
| Atlas storage full | Atlas → Collections: `uploads.chunks` holds photos; delete old progress photos in the app |
